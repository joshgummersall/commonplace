Your highlights, back where you'll read them.

Highlights on an e-reader pile up in My Clippings.txt and are never seen again. Commonplace imports them, searches them by words and by meaning, suggests tags from what similar highlights carry, and hands a few back each day. One binary, one database file, on your own machine.

Daily

About ten highlights a day. The ones you haven't seen in longest come up first; favorites come up more often, and no two make nearly the same point. The set stays fixed for the day.

Tags

What do you keep underlining? Commonplace can group highlights that say related things, usually across books, and have a local model name each group as a suggested tag. After that, each new highlight is suggested the tags most of its nearest neighbors carry. Suggestions look muted until you confirm them. Fix any tag on a quote; a tag you remove is never suggested for it again. Rename, merge, or delete tags as you like.

What it does

  • Imports Kindle and CrossPoint clippings Re-import any time. It skips what it has, keeps the final version of a highlight you extended or trimmed, and keeps your notes.
  • Searches by words and meaning together Meaning comes from a local embedding model in Ollama. Without Ollama, search falls back to words.
  • Suggests tags you can correct Groups related highlights by meaning, named by a local model, then tags new highlights from their neighbors. Confirm, fix, or remove any tag; filter Search by tag.
  • Keeps notes, favorites, and burials Write dated notes on any quote. Favorite what you want to see more; bury what you don't want to see again.
  • Stays on your machine No accounts and no sync service. The web app listens on localhost, and cmpl backup writes snapshots safe for iCloud Drive.

Install

brew install --cask joshgummersall/commonplace/commonplace

For search by meaning and tag suggestions, add Ollama with an embedding model and a model to name tags (optional):

ollama pull qwen3-embedding:0.6b
ollama pull qwen2.5:14b

Use

cmpl import "/Volumes/Kindle/documents/My Clippings.txt"
cmpl serve                     # http://127.0.0.1:8420

Keys

The web app is built for the keyboard, with vim-style keys. Press ? in the app for the full list.

j k gg G
Move between quotes, with counts (5j)
o / h
Open a quote / go back
/ gd gt gf
Search, Daily, Tags, favorites only
t T
Edit the quote's tags, confirm its suggested tags
f b s
Favorite, bury, more like this
i cc dd
Write, edit, delete a note; on the Tags page, rename or delete a tag
m
Merge a tag into another, on the Tags page
yy u
Copy the quote with its source, undo

For agents

Read commands print JSON, so an agent such as Claude Code can work with your library. cmpl help documents every command. They never change your highlights. cmpl tags lists tags, and --tag narrows list and search to one.
