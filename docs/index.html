Your highlights, back where you'll read them.

Highlights on an e-reader pile up in My Clippings.txt and are never seen again. Commonplace imports them, searches them by words and by meaning, finds the themes that run across your books, and hands a few back each day. One binary, one database file, on your own machine.

Daily

About ten highlights a day. The ones you haven't seen in longest come up first; favorites come up more often, and no two make nearly the same point. The set stays fixed for the day.

Themes

What do you keep underlining? Commonplace groups highlights that say related things, usually across books, into broad areas holding specific themes, and a local model names each one. Open a theme to read its highlights, most typical first. Rename any theme; your names are kept.

What it does

  • Imports Kindle and CrossPoint clippings Re-import any time. It skips what it has, keeps the final version of a highlight you extended or trimmed, and keeps your notes.
  • Searches by words and meaning together Meaning comes from a local embedding model in Ollama. Without Ollama, search falls back to words.
  • Finds themes across your books Groups related highlights by meaning, with names from a local model. Refresh them after an import; filter Search by theme.
  • Keeps notes, favorites, and burials Write dated notes on any quote. Favorite what you want to see more; bury what you don't want in Daily.
  • Stays on your machine No accounts and no sync service. The web app listens on localhost, and cmpl backup writes snapshots safe for iCloud Drive.

Install

brew install --cask joshgummersall/commonplace/commonplace

For search by meaning and themes, add Ollama with an embedding model and a model to name themes (optional):

ollama pull qwen3-embedding:0.6b
ollama pull qwen2.5:14b

Use

cmpl import "/Volumes/Kindle/documents/My Clippings.txt"
cmpl serve                     # http://127.0.0.1:8420

Keys

The web app is built for the keyboard, with vim-style keys. Press ? in the app for the full list.

j k gg G
Move between quotes, with counts (5j)
o / h
Open a quote / go back
/ gd gt gf
Search, Daily, Themes, favorites only
t
The quote's theme
za zR zM
Open or close an area, all areas
R
Refresh themes
f b s
Favorite, bury, more like this
i cc dd
Write, edit, delete a note; cc also renames a theme
yy u
Copy the quote with its source, undo

For agents

Read commands print JSON, so an agent such as Claude Code can work with your library. cmpl help documents every command. They never change your highlights. cmpl themes lists themes, and --theme narrows list and search to one.

cmpl search 'fear of failure' --limit 1
